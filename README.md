### 本版变化

1. **断线拆成两个模式**：模式 3 第一段断线保留原动作（右弧 1s → 直行 60/60 → 出口弧 0.5s）；模式 4 第二段断线改为确认断线后停车 0.2s，再执行**一整段右弧 73/62 共 3.0 秒**（转速差更小、行程基本不变），之后继续沿黑线驶向终点，识别多条平行横线并在通过后 1 秒内停车。
2. **丢线不再停车**：普通循迹丢线后先保持约 0.1 秒最后修正，再朝最后见线方向（无方向默认向右）持续转向找线，直到模式限时或按键停止；不再有 0.5 秒丢线故障停车。
3. **保留弯口判读优化**：模式 2 判据为“该侧最外侧探头（右弯 X8、左弯 X1）+ 中央探头”，并有全白漏判兜底和一次方向自纠正。
4. **保留断线差速补偿**：接近段闭环循迹学习左右差速补偿，叠加到两段断线的开环弧线/直行段，避免直行跑偏。
5. **右环岛出口延长**：出口最少行驶 75 拍（约 0.375 秒）、连续 10 拍中央线确认；出口阶段左轮 +5、右轮 −5 轻微右修正，防止出弯跑出黑线。
6. **两个环岛分开判定**：左环岛出口必须走满七段直线（一整圈）；右环岛不数直线段，改由 X1/X2 看到黑线判定出口，环内按普通循迹走。

## 诊断工具

`八路循迹_方向核验工程/` 是不跑循迹的核验固件：数码管交替显示八路原始图案的高半字节（X5～X8）和低半字节（X1～X4），按键以 500ms 短脉冲交替核验左右轮。用于确认接线与读取弯口图案，说明见工程内 `方向核验操作说明.md`。
